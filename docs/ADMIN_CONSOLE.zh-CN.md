# GPTTool 系统管理后台

系统管理后台由公网中继直接提供，默认地址为自托管入口后的 `/admin/`。只有 PostgreSQL 中 `role = 'admin'` 的登录账号能够访问。

## 功能

- 概览：用户总量、在线用户、在线设备、活跃控制页面、有效会话、队列快照和 24 小时趋势；
- 用户：搜索账号、查看设备与在线状态、禁用普通账号或授予管理员角色；
- CDP 规则：查看精确支持的 ChatGPT 版本、采集上传时间、最后编辑时间和实测结果；编辑优先级或规则 JSON，并可停用、重新启用或删除规则；
- 系统配置：在线调整注册开关、二维码有效期、登录会话有效期、账号设备上限、设备中心公告和下载基础地址。

所有修改都会写入 PostgreSQL，敏感生产环境变量仍保留在服务器外部环境文件中，不通过管理后台读取或公开。

## 系统管理员保护

用户名为 `admin` 的账号会在数据库迁移时自动标记为系统管理员，不能在后台被禁用或降级。部署者应在首次初始化后立即设置高强度密码，并限制数据库和环境文件权限。

## CDP 规则格式

后台只接受声明式 JSON，拒绝可执行脚本。新规则不能仅凭“采集到了选择器”发布：私有采集器必须先把候选规则装入 GPTTool 实际使用的适配器，在对应官方客户端版本和平台上完成编辑器、任务读取、模型、推理强度、响应速度、额度读取、消息发送、回复确认和原任务恢复测试。全部通过后，服务端才接受上传并赋予保留的最高匹配优先级。

规则至少包含：

```json
{
  "schemaVersion": 1,
  "id": "chatgpt-macos-example",
  "exactOfficialVersion": "26.901.20858 (7658)",
  "updatedAt": "2026-09-04T00:00:00.000Z",
  "selectors": {}
}
```

客户端按官方应用的完整版本（含构建号）和平台匹配规则；没有匹配项时回退到随客户端发布的内置兼容规则。历史规则不会因数据库升级被伪造上传时间，也不会被自动删除；后台以“未记录”标记旧数据。

后台的编辑、启用、停用和删除操作仅向管理员开放。修改已验证规则的选择器、标签、app-server 映射、平台或最高优先级后，必须重新执行功能验证，防止“验证后篡改”的规则上线。
