# GPTTool 系统管理后台

系统管理后台由公网中继直接提供，默认地址为自托管入口后的 `/admin/`。只有 PostgreSQL 中 `role = 'admin'` 的登录账号能够访问。

## 功能

- 概览：用户总量、在线用户、在线设备、活跃控制页面、有效会话、队列快照和 24 小时趋势；
- 用户：搜索账号、查看设备与在线状态、禁用普通账号或授予管理员角色；
- CDP 规则：查看支持的 ChatGPT 版本范围，上线、停用或删除云端兼容规则；
- 系统配置：在线调整注册开关、二维码有效期、登录会话有效期、账号设备上限、设备中心公告和下载基础地址。

所有修改都会写入 PostgreSQL，敏感生产环境变量仍保留在服务器外部环境文件中，不通过管理后台读取或公开。

## 系统管理员保护

用户名为 `admin` 的账号会在数据库迁移时自动标记为系统管理员，不能在后台被禁用或降级。部署者应在首次初始化后立即设置高强度密码，并限制数据库和环境文件权限。

## CDP 规则格式

后台只接受声明式 JSON，拒绝可执行脚本。规则至少包含：

```json
{
  "schemaVersion": 1,
  "id": "chatgpt-macos-example",
  "minOfficialVersion": "1.2026.200",
  "maxOfficialVersion": "1.2026.260",
  "selectors": {}
}
```

客户端按官方应用版本和平台匹配规则；没有匹配项时回退到随客户端发布的内置兼容规则。
