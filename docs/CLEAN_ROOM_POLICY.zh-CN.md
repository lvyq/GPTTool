# 洁净室开发与来源规则

本规则适用于 GPTTool 的维护者、贡献者和衍生发行者。

## 可以使用的资料

- 用户可观察到的产品行为和独立编写的需求规格；
- 公开标准、公开协议与官方 API 文档；
- 许可证兼容并已记录在第三方通知中的依赖；
- 贡献者本人创作且有权授权的代码、测试、文案与素材。

## 禁止提交

- Codex-Mini/GPT Mini 或其他类似项目的源码、HTML/CSS、选择器、图片、图标、文案或反编译结果；
- ChatGPT、OpenAI、Codex 或其他第三方的商标素材和未授权资源；
- 生产服务器 IP、域名专用配置、密码、Token、私钥、用户日志或数据库；
- 来源不清或许可证不兼容的代码片段、规则库、模型、字体和媒体文件；
- 安装包、自动更新产物、node_modules、构建目录和用户上传文件。

## 贡献证据链

1. Issue 先描述行为和验收标准，避免粘贴第三方实现；
2. PR 说明实现来源与新增依赖许可证；
3. CI 执行测试、静态检查和敏感信息扫描；
4. 发布前执行代码克隆扫描、资源 SHA-256 交集检查和人工 UI/商标审查；
5. 对疑似衍生实现先隔离，不在来源未澄清时合并。

## 发布前基线审计

2026-08-11 对 GPTTool 与 `CoimgRain/Codex-Mini` main 分支执行：

- jscpd（最少 6 行、60 token）跨项目源码扫描：**未发现跨项目克隆**；
- 源码内部有少量公共 RPC/错误处理模板重复，不涉及 Codex-Mini；
- 图片与二进制资源 SHA-256 交集：**0 个命中**；
- 生产域名、IP、安装包、部署记录和密钥类文件：从公开清单排除并改用示例配置。

审计只能降低风险，不能替代法律意见。若计划商业发行，应由知识产权律师在指定提交上复核。
